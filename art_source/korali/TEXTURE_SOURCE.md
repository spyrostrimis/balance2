# Stone source texture

Created for Balance's Korali study using the built-in `image_gen` tool in this
project conversation on 9 November 2026. No external source image was supplied.
Original output copied unchanged to `stone_basecolor_source.png` and packed in
`korali_authoring.blend`. This is generated project art, not a CC0 asset pack.
Turquoise mineral design is added in Blender, not generated into this texture.

Exact generation prompt:

> Create a production-ready square seamless tileable BASE COLOR texture for a stylized-realism 3D stone asset in a polished fantasy science-fiction RTS. This is a material texture, NOT a picture of a rock, NOT a scene, no perspective. Entire canvas is a straight-on orthographic scan of the same continuous dark slate-grey weathered metamorphic rock surface. Rich painterly geological detail: angular fractured dark slate plates, layered compressed grain, faint oxidized muted ochre and warm tan deposits collecting in cracks, chipped lighter edges, very fine mineral speckling. Large irregular stone shapes at three different scales, subtle directional geological layering diagonally, broken natural non-repeating fissures. Restrained color: charcoal blue-grey and warm grey, with sparse dusty copper-brown accents. Medium values with readable variation, no black holes. Flat diffuse even illumination with NO cast shadows, no ambient directional lighting, no bright highlights, no depth of field, no vignette. NO turquoise, NO green, NO glowing veins, NO crystals, NO grass, NO text, NO border. Painterly tactile stone detail closer to high-quality hand-painted strategy-game environment textures, not flat low-poly color, not cartoon outlines, not a noisy photograph. Edges must tile seamlessly in both directions. Highest useful texture detail, square format.

The prompt expresses the requested texture properties; it is not a guarantee of
perfect tiling or physically measured albedo. Box projection and UV baking are
used for this particular mesh. The Godot study applies a documented slate tint.
